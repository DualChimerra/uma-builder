# 🏇 Uma Deck Builder

**Составитель колод карт поддержки для Uma Musume: Pretty Derby (Global)**

🌐 **Приложение:** https://dualchimerra.github.io/uma-builder/

Статическое веб-приложение без бэкенда: вся база хранится в репозитории, инвентарь — в браузере (localStorage). Работает на GitHub Pages.

---

## Специфика игры (зачем это всё)

В Uma Musume перед забегом-тренировкой (Career) собирается **колода из 6 карт поддержки**:
**5 своих + 1 заимствованная** у другого тренера (friend support).

Карты бывают 7 типов — Speed / Stamina / Power / Guts / Wit (Intelligence) / Friend / Group — и трёх редкостей (R / SR / SSR). Каждая карта:

- даёт **скиллы-хинты** (на совместных тренировках можно получить скидку и выучить скилл);
- даёт **скиллы из ивентов** карты (не гарантированы — зависят от выпадения ивентов);
- имеет **уровень анлока** (limit break, LB 0–4): чем выше, тем сильнее её тренировочные бонусы (R: ур. 20→40, SR: 25→45, SSR: 30→50).

Скиллы бывают **обычные (белые)** и **золотые** (усиленные версии, ◎). Собрать колоду, которая закрывает нужный набор скиллов и при этом сбалансирована по типам — та ещё головоломка. Это приложение решает её автоматически.

## Возможности

- **📚 База карт** — все карты поддержки с картинками, фильтрами по типу/редкости, деталями (хинты, ивентовые скиллы, эффекты поддержки).
- **✨ База скиллов** — все скиллы, которые дают карты: описание, золотой/обычный, какие именно карты его дают (хинт или ивент).
- **🎒 Инвентарь** — отмечай свои карты и уровень анлока (LB 0–4). Сохраняется между сессиями, есть **экспорт/импорт бекапа** (JSON).
- **⚡ Составитель колоды** — главный режим:
  - выбираешь нужные скиллы и ставишь каждому приоритет **1 / 2 / 3**;
  - задаёшь минимум карт нужных типов («не меньше 2 Speed» и т.п.);
  - приложение собирает колоду: **5 карт из инвентаря + 1 заимствованная** из всей базы (считается MLB), максимально закрывающая оставшиеся потребности;
  - показывает покрытие: какой скилл с какой карты приходит (хинт/ивент), что не закрыто.
- **⚙️ Настройки** — тема, пул карт (Global-only / все JP), тонкая настройка весов алгоритма, бекапы, сброс. Раздел будет пополняться.
- **🌗 Тёмная и светлая тема**, адаптивная вёрстка.

## Как работает подбор (алгоритм)

Жадный алгоритм с учётом покрытия. На каждом шаге выбирается карта с максимальным приростом ценности:

| Фактор | По умолчанию |
|---|---|
| Вес скилла приоритета 1 / 2 / 3 | 100 / 55 / 25 |
| Множитель золотого скилла | ×1.6 (золотой P1 > обычный P1) |
| Множитель ивентового скилла | ×0.65 (не гарантирован) |
| Повторное покрытие скилла | ×0.15 от веса |
| «Качество» карты (редкость + LB) | SSR 30 + 5·LB, SR 18 + 3·LB, R 8 + 2·LB |

Правила:

- в колоде не может быть двух карт одного персонажа (как в игре);
- ограничения по типам соблюдаются через проверку выполнимости на каждом шаге; если инвентаря не хватает — заполняет слоты лучшим из возможного и честно предупреждает;
- заимствованная карта подбирается в конце, когда известны «дыры» покрытия — поэтому она закрывает самое ценное из оставшегося (обычно важный золотой скилл);
- качество карты (uncap) работает как приоритет при прочих равных: из двух карт с одинаковым покрытием выбирается более раскрытая, но очень важный скилл перевесит низкий LB.

Все веса настраиваются в разделе «Настройки».

## Данные

Источник — [GameTora](https://gametora.com/umamusume). В репозитории лежит обработанный снапшот:

- `data/cards.json` — карты поддержки (тип, редкость, хинты, ивентовые скиллы, эффекты, даты релиза JP/Global);
- `data/skills.json` — скиллы, которые дают карты;
- `data/effects.json` — названия эффектов поддержки;
- `assets/supports/`, `assets/skills/` — иконки карт и скиллов.

Фильтр «только глобальная версия» опирается на дату релиза EN (`release_en`).

### Обновление данных

```bash
node scripts/update-data.mjs           # данные + докачка новых картинок
node scripts/update-data.mjs --no-assets  # только данные
```

Скрипт читает манифест GameTora, скачивает свежие `support-cards` / `skills`, пересобирает JSON приложения и докачивает недостающие иконки. После — закоммитить и запушить.

## Разработка

Никакой сборки — чистый HTML/CSS/JS (ES-модули). Локально:

```bash
python3 -m http.server 8641
# открыть http://localhost:8641
```

Структура:

```
index.html          — оболочка приложения
css/style.css       — стили (светлая/тёмная тема)
js/data.js          — загрузка БД, индексы
js/store.js         — localStorage-состояние, импорт/экспорт
js/builder.js       — алгоритм составления колоды
js/views.js         — рендер вкладок и модалок
js/app.js           — инициализация, вкладки
scripts/update-data.mjs — обновление данных с GameTora
```
